# СПП, 7 семестр — лабораторные работы

Одно и то же приложение «менеджер задач», реализованное двумя разными способами.

| | Работа | Стек | Запуск |
|---|--------|------|--------|
| [Lab1](Lab1/README.md) | Серверный рендеринг | Node.js + Express + EJS, данные в JSON-файле | `cd Lab1 && npm install && npm start` → <http://localhost:3000> |
| [Lab2](Lab2/README.md) | SPA + REST API | React + Vite, Express + PostgreSQL, Docker | `cd Lab2 && docker compose up --build` → <http://localhost:8088> |

Подробное описание каждой работы — в её собственном `README.md`.
